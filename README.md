# Darbuka Practice

Android landscape-only Persian Darbuka practice app.

## Features
- 33 fixed exercises from the supplied book pages
- Local notation artwork (cropped to show the exercise notation only)
- 40–250 BPM, 4/4 metronome
- Three built-in click sounds
- Independent circular BPM and volume controls
- Practice timer linked to metronome start/pause/resume/stop
- Room practice history
- Jalali dates
- BPM/time graphs and progress dashboard
- Fully offline
- GitHub Actions Gradle build

## Build
Open the project in Android Studio and run `assembleDebug`, or push it to GitHub and use the included Actions workflow.

The app itself has no network dependency.
